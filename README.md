# Frost Manifest

A freezer inventory tracker: add items, adjust quantities, and see what's expiring soon.
Built as a Claude Artifact so it stays in sync live across every phone that opens it — no
backend to host or accounts to set up.

`index.html` is a snapshot of the published page for version history. The live, syncing
copy is the Artifact link shared with the household — that page reloads automatically on
every device whenever anyone adds, edits, or removes an item.
